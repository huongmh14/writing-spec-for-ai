## How to Use

1. **Trước khi AI code:** Đọc spec, copy checklist từ `scripts/spec-evaluation-checklist.md`
2. **Sau khi AI xong:** Đánh giá theo checklist, ghi vào log này
3. **Định kỳ:** Review log để xem trend

---

## Scoring System

- **5/5 Yes:** Spec hiệu quả
- **3-4/5 Yes:** Chấp nhận được, cần cải thiện
- **1-2/5 Yes:** Spec không hiệu quả

---

## Health Indicators

### Good Signs (đang đi đúng)
- AI đọc spec trước khi code
- Code theo spec, không lệch
- AI hỏi khi mơ hồ
- AI có bằng chứng test
- Bug rate giảm
- Onboarding nhanh hơn

### Warning Signs (cần điều chỉnh)
- AI ignore spec
- Code không có spec
- Spec outdated
- Team không review spec
- AI bịa requirement
- Spec quá nặng hoặc quá nhẹ
