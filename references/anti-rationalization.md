## Anti-Rationalization (Red Flags — Stop Immediately If Thinking)

| Rationalization under time pressure / authority | Mandatory action |
|---|---|
| *"Small project / in a hurry, write `AGENTS.md` directly and skip Gate-1 proposal"* | **Stop.** Small projects use Profile `S` (compact ~15-line proposal), still requiring Gate-1 sign-off before creating repo files. |
| *"Only a few small details missing, just guess them for speed"* | **Stop.** Mark `[NEEDS CLARIFICATION]` or ask via `HYPOTHESIS + GUESS` at Step 4; never fabricate REQ/AC. |
| *"Self-review looks fine, present directly without `spec-challenger` / `codex` cross-review or `doc-tester`"* | **Stop.** A model that writes and grades itself has confirmation bias and shared blind spots (**independent clean-session & cross-model challenge**, `C26`). Before presenting spec/design/code to the user, run the loop `Write → Independent challenge catches errors (second-model CLI like codex read-only or clean-session subagent receiving only ARTIFACT + CONTRACT) → Self-fix real errors` then present with the self-fix report. |
| *"AI output sounds plausible so mark it `Verified`, or just throw jargon + one short line because the user only clicks Self-check"* | **Stop.** Can't open a source + matching quote → only `AI proposed` / `Unknown` allowed (`C31`). Don't hide explanation cards in `<!-- ... -->` comments; must explain *What it is + example · Why needed (what breaks if skipped) · How it runs · Self-check ≤ 5 min · Source* so the user truly understands the AI-written knowledge. |
| *"Present direction as long prose / only report 'All tests passed' is enough"* | **Stop.** Long prose makes readers nod without understanding (**visual direction presentation**, `C28`: Scope Radar green/yellow/red, Mermaid diagrams, input/output examples). Reporting green tests while hiding inputs/outputs/mocks is unverifiable (**visible test evidence**, `C29`: print the test-run evidence table). |
| *"Gate 1 passed, write all of `AGENTS.md`, `glossary`, `decisions`, and every `SPEC-xx` in one pass for speed"* | **Stop.** Violates `C30`: each Step-5 turn does **one sub-step** (5a → stop for review → 5b one spec at a time → stop for review → 5c). |
| *"Read multiple sub-skills + `principles.md` + `base-kit.md` at once for safety / or skip opening the current step's sub-skill"* | **Stop.** Each turn opens **exactly 1 `skills/<current-step>/SKILL.md`**; forbidden to pre-read next-step sub-skills or bulk-load heavy `references/` files and blow the context window (`C17`). |
